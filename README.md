# API Test Automation Suite

Python API tests against [JSONPlaceholder](https://jsonplaceholder.typicode.com) using **pytest**, **requests**, and **jsonschema**, with a **Scout HQ**-inspired dark theme for the demo UI and pytest-html reports.

## Layout

```
.
├── app.py              # Flask: serves ui/ and report
├── pytest.ini          # HTML report → ui/report.html + theme CSS
├── requirements.txt
├── run_tests.py        # CLI: runs pytest (e.g. for simple hosting hooks)
├── run_ui_demo.bat     # Windows: install, test, open HTML files
├── RUN_UI.md           # UI / Live Server / Flask notes
├── assets/
│   └── style.css       # Theme for pytest-html (embedded in report)
├── tests/
│   ├── test_users.py
│   └── test_posts.py
├── ui/
│   ├── index.html      # Demo dashboard
│   ├── theme.css
│   └── report.html     # generated by pytest (gitignored)
└── utils/
    ├── api_client.py
    └── schemas.py
```

## Quick start

```bash
pip install -r requirements.txt
pytest
python app.py
```

Optional (local auto-reload): set `FLASK_DEBUG=1` before `python app.py`.

- Dashboard: http://127.0.0.1:5000/
- Report: http://127.0.0.1:5000/report.html

Regenerate the report after changing tests or `assets/style.css` by running **`pytest`** again.

## CI

GitHub Actions runs `pytest` on push (see `.github/workflows/tests.yml`).

The demo theme is inspired by tactical / survival fiction aesthetics and does not include third-party franchise assets.
